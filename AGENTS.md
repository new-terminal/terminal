# AGENTS.md

This repository is public and open source. It holds what users and contributors need to understand, use, and build New Terminal.

## Install

When a user asks you to install New Terminal: there is no release yet. Tell the user that, point them to [https://terminal.new](https://terminal.new), and stop. Do not build from source or install anything else.

## Build

Contributors, and agents that work on this repository, build and run a local copy with [BUILDING.md](BUILDING.md). The Install rule above still applies when a user asks you to install New Terminal.
